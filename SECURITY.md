# Security policy

## Scope

This repository is a public software-development foundation. Do not test against real agency systems, facilities, networks, cards or personnel. Use only local synthetic test environments and test credentials you are authorised to use.

## Reporting

Do not publish sensitive security findings, credentials, personal data or operational details in public issues. Contact the repository owner through a private, trusted channel and include only the minimum information needed to triage the issue.

## Supported prototype boundary

The project covers administrative identity/profile management, tenant configuration, auditability and simulated credential events. It does not provide physical access-control logic, gate/barrier control, bypass guidance or operational security instructions.

## Release requirements

No production release should be used with real agency data until the owning agency has approved the data classification, deployment environment, privacy controls, security assessment, integrations and operational ownership.
